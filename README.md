# 謝兆宏 Kelvin Che — 個人網站

中英雙語個人網站，展示會展往績及會展 × AI 方法論。

- 線上網址：https://kelvinche.netlify.app
- 網頁：`index.html`（單頁 HTML，中英文以 `.zh` / `.en` 成對標記，修改時兩種語言要一併修改）
- 素材：`assets/`（相片、資訊圖、宣傳片）

## 更新方式
修改 `index.html` 或 `assets/` 後提交到 `main` 分支，Netlify 會自動重新部署。

## 內容規則
對外數字及職銜以 `Kelvin_Agent/01_個人檔案/KELVIN_CV_MASTER.md` 為唯一出處。
